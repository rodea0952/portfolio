# portfolio

GitHub Pages で公開するポートフォリオサイトです。

## 構成

- `index.html` — トップページ（要約・代表的な実績・各ページへの入口）
- `about.html` — 前提系：プロフィール・経歴・スキル
- `works.html` — アウトプット系：実績・制作物・技術記事（アメリエフ スタッフブログ／個人のはてなブログへのリンク。アメリエフの記事サムネははてなの画像サーバーから直接表示）
- `contact.html` — 連絡先
- `style.css` — 全ページ共通のスタイル（色は `:root` の変数で管理）

ヘッダーとフッターは全ページに同じものを書いています。ナビを変えるときは全ページを直してください。

## 実績・制作物の追加

`works.html` の `#achievements` 内の `li`、`#projects` 内の `article.card` をそれぞれコピーして書き換えてください。
